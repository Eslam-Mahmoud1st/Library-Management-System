# Library Management System

A desktop-based Library Management System developed using **Java Swing**, **JDBC**, and **SQL Server**.

## Features

- Add, view, search, update, and delete books
- Borrow and return books
- Login system
- Database statistics using SQL functions such as `COUNT`, `MAX`, and `MIN`
- Real-time date and time display
- Interactive graphical user interface
- SQL Server database integration using JDBC

## Technologies

- Java
- Java Swing
- JDBC
- SQL Server
- SQL
- Object-Oriented Programming (OOP)
